## Policy

- A dependency is added only with a written reason (what it replaces, size, maintenance, licence), and only under a permissive licence.
- `Cargo.lock` is committed; CI builds with `--locked`; `cargo deny check` (advisories, licences, bans, sources) runs on every push to main, every pull request, once a week and on the tagged commit before a release; every release carries the SBOM.
- C code in the dependency tree: SQLite (bundled), the tree-sitter runtime and grammars. No other native code; no networking crates.
